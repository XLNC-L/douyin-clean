# 抖音净播 · Douyin Clean

一个针对**网页版抖音**（`www.douyin.com`）的 Chrome 扩展：自动最高清晰度、失焦暂停、纯净布局、直播 / 广告跳过。
所有功能都是**事件驱动**实现，不轮询、不做全站 DOM 监听，刷视频不会卡。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动最高清晰度 | 每条视频自动选到最高档；菜单里出现 4K 时优先 4K，实测到 4K 后本次会话不再调整 |
| 失焦自动暂停 | 窗口失去焦点 / 切到后台时暂停，回到页面**不会**自动恢复（不会和你抢播放控制） |
| 浮层自动隐藏 | 视频边缘文案、右侧互动栏、底部控制条：鼠标进入画面或移动时显示，静止 2 秒或移出画面 2 秒后淡出 |
| 左侧导航隐藏 | 隐藏抖音左侧导航，让视频区域占比更大 |
| 直播 / 广告跳过 | 识别推荐流中的直播、广告、推广视频并自动切到下一条；头像旁弹出的直播小窗自动关闭 |
| 顶栏精简 | 右上角只保留头像、通知、消息，其余图标隐藏（私信抽屉不受影响） |
| 评论区 | 保持手动开关，打开 / 收起照旧 |

## 为什么不会卡

刷抖音卡顿通常来自插件本身：全站 `MutationObserver(subtree)`、`setInterval` 轮询 `querySelectorAll`、运行时反复改样式触发重排。

本扩展的约束：

- **视觉改动全部写在静态 CSS 里**（[css/content.css](css/content.css)），页面加载后运行时零样式计算；
- **新视频检测靠媒体事件**（`loadedmetadata` / `playing` / `emptied`），另加一个 2 秒一次、只比对 `<video>` 引用与 `src` 的轻量看门狗兜底；
- **不删 DOM 节点**：过滤广告只负责切到下一条，绝不动列表结构，虚拟列表与滚动吸附逻辑不受影响；
- **不轮询查询选择器**，需要等待时用事件或短时 `await sleep` 的有限次循环。

## 安装

### 方式一：下载 Release 压缩包（推荐）

1. 打开 [Releases](https://github.com/XLNC-L/douyin-clean/releases/latest)，下载最新的 `douyin-clean-v*.zip`；
2. 解压到一个固定目录（之后不要删，Chrome 会一直从这里加载）；
3. 打开 `chrome://extensions`，右上角开启「开发者模式」；
4. 点「加载已解压的扩展程序」，选择解压后的目录（含 `manifest.json` 的那一层）；
5. 打开 `https://www.douyin.com/` 即可生效。

升级时下载新 Release 覆盖原目录，再到扩展管理页点一下「刷新」按钮，刷新抖音页面。

### 方式二：克隆仓库

```bash
git clone https://github.com/XLNC-L/douyin-clean.git
```

然后用「加载已解压的扩展程序」选择仓库目录。

## 调试

在抖音页面按 `Ctrl + Shift + D`：

- 控制台输出当前状态（版本、播放器尺寸、清晰度组件档位、实测分辨率、广告判定、被隐藏的顶栏项）；
- 给被隐藏 / 被标记的浮层加 2.5 秒青色描边，方便确认定位是否正确。

清晰度相关日志前缀为 `quality:`，例如：

```
[抖音净播] quality: 当前=高清1080P 实测=1920p 最高档=超清4K
[抖音净播] quality: 点档位 超清4K
[抖音净播] quality: 实测已到 4K(3840)，后续不再调整
```

## 结构

```
manifest.json      MV3 声明：内容脚本、图标、匹配规则
css/content.css    全部视觉改动（静态 CSS）
js/core.js         公共命名空间、选择器、工具函数
js/quality.js      自动最高清晰度
js/overlay.js      视频浮层显隐
js/filter.js       直播 / 广告过滤、直播小窗关闭
js/header.js       顶栏图标精简
js/main.js         启动、新视频检测、失焦暂停、调试
```

## 已知限制

- 只适配 `www.douyin.com` 桌面网页版，不支持手机网页版与抖音客户端；
- 抖音前端类名是哈希动态生成的，扩展只依赖 **ID / `data-e2e` / 几何特征 / 语义文本** 定位元素。抖音大改版后可能需要跟进；
- 清晰度取决于视频本身提供哪些档位：视频没有 4K 源时，抖音会把 4K 顺延到可用的最高档，扩展会接受这个结果。
